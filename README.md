A single original one-line wedding vow for a robot couple, written by `main.ts` to `/output/entry.txt` (one line, 135 characters, inside the 160-character gate).

> I take you to be my lawfully wedded co-processor, to have and to hold, in sickness and in low battery, till a factory reset do us part.

Run it with Node 22:

```sh
node main.ts
```
